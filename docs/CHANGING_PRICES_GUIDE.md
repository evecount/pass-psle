# Technical Guide: How to Change Product Prices

This document outlines the step-by-step process for safely changing the price of a product (e.g., a mock exam) in the application. The system is designed to be robust, but it requires a precise procedure to ensure new customers are charged the new price while maintaining access for existing customers.

## Core Architecture Overview

The pricing and access control system relies on a clean separation between our internal Quiz IDs and Stripe's Price IDs.

1.  **The "Dictionary" - `src/lib/stripe-price-ids.ts`**: This is the most critical file. It acts as a map, connecting your internal Quiz ID (e.g., `'res-5'`) to the specific Price ID generated by Stripe (e.g., `'price_1SU7SvDhpURidIjUCmirEzvL'`).

2.  **The "Doorman" - Stripe Webhook (`src/app/api/stripe/webhooks/route.ts`):** When a user successfully makes a purchase, Stripe notifies our webhook. This webhook then saves the **Stripe Price ID** into the user's `purchasedExams` array in their Firestore document. It does **not** save the internal quiz ID. This is the "key" the user holds.

3.  **The "Gatekeeper" - Dashboard (`src/app/dashboard/page.tsx`):** When the dashboard loads, it checks if a user has access to a quiz. For each quiz, it:
    *   Takes the internal quiz ID (e.g., `'res-5'`).
    *   Looks up the corresponding Stripe Price ID in the "Dictionary" file.
    *   Checks if the user's list of purchased keys (`purchasedExams`) includes that specific Stripe Price ID. If it does, access is granted.

This architecture ensures that if you change a price in Stripe (which creates a new Price ID), you only need to update the "Dictionary" file. Old customers will still have access because they hold the old Price ID in their records.

## Step-by-Step Guide to Changing a Price

Follow these steps exactly to change the price for a one-time purchase or subscription.

### Step 1: Create a New Price in Stripe

1.  Log in to your **Stripe Dashboard**.
2.  Navigate to the **Product catalogue**.
3.  Find the Product you want to change the price for (e.g., "RES5 Mock Exam"). **Do not edit the existing price.** Instead, you must create a new one.
4.  In the Product's detail page, click the **"+ Add another price"** button.
5.  Configure the new price (e.g., enter `$50.00`, set it to "One-time").
6.  Save the new price.

### Step 2: Copy the New Price ID

1.  After saving, you will be on the Product detail page.
2.  Find the new price you just created in the "Pricing" list.
3.  Click on the new price to view its details.
4.  Copy its **API ID**. It will look like `price_xxxxxxxxxxxxxxxxx`.

### Step 3: Update the "Dictionary" File

1.  Open your codebase and navigate to the file: `src/lib/stripe-price-ids.ts`.
2.  Locate the entry for the quiz you are updating (e.g., `'res-5'`).
3.  Paste the new Price ID you copied from Stripe, replacing the old ID for the corresponding payment type (`oneTime` or `subscription`).

**Example (Before):**
```javascript
export const stripePriceIds = {
    //...
    'res-5': {
        oneTime: 'price_1SU7SvDhpURidIjUCmirEzvL', // This is the old $60 price
        subscription: 'price_1SU7KkDhpURidIjU4j1Vtswy'
    },
    //...
};
```

**Example (After):**
```javascript
export const stripePriceIds = {
    //...
    'res-5': {
        oneTime: 'price_1XYZabCNov3idIjUABCdefGH', // This is the new $50 price
        subscription: 'price_1SU7KkDhpURidIjU4j1Vtswy'
    },
    //...
};
```

### Step 4: Deploy Your Changes

Commit and deploy the updated `stripe-price-ids.ts` file. Once deployed, the checkout buttons on your site will automatically use the new Price ID, and new customers will be charged the new price.

## Critical Risk: ID Mismatch

The only point of failure in this system is a typo or mismatch between the IDs in `src/lib/quiz-data.ts` and the keys in `src/lib/stripe-price-ids.ts`.

For example, if `quiz-data.ts` has `id: "res-5"` but `stripe-price-ids.ts` has a key of `'res5'` (no dash), the lookup will fail, and no one will be able to purchase or access that quiz.

**Always ensure the IDs match character-for-character.**
