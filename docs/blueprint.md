# **App Name**: Quiz Ace

## Core Features:

- Test Upload: Allow the user to upload the test questions and correct answers from two different years of papers, ensuring exact correspondence.
- Interactive Quiz: Present the test in an interactive format where users can select answers.
- Instant Feedback: Provide immediate feedback on selected answers, indicating whether the answer is correct and, if incorrect, show the correct answer.
- Performance Tracking: Track the user's progress and performance on the test.
- Completion Status: Allow user to iterate through the test until they achieve 100% and store the results in Firestore.
- AI Hint Tool: Use AI tool, triggered by the user on request, to obtain a useful hint.

## Style Guidelines:

- Primary color: Vivid blue (#4285F4), evoking trust, clarity, and intelligence.
- Background color: Light blue (#E3F2FD), creating a calm, focused environment with a hue similar to the primary but significantly desaturated.
- Accent color: Green (#34A853), an analogous color to the primary blue. The hue is close but slightly shifted (approx. 30 degrees to the right), which is brighter and more saturated to contrast strongly and indicate correct answers.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, and 'Inter' (sans-serif) for body text.
- Use clear and intuitive icons to represent different features and actions, ensuring ease of use and quick understanding.
- Clean and organized layout with clear visual hierarchy, making it easy for users to navigate the test and understand feedback.
- Subtle animations to provide visual feedback and enhance user engagement, such as highlighting correct answers or providing encouraging messages.
