# Pass-Exams.com - AI-Powered CMFAS Study Platform

This project is an advanced, AI-powered study platform designed to help candidates pass Singapore's CMFAS (Capital Markets and Financial Advisory Services) exams on their first attempt.

## Core Idea

Traditional study methods for professional certifications often rely on static, outdated materials like PDFs, leading to rote memorization rather than true understanding. This platform leverages AI to create a dynamic, interactive, and highly effective learning experience that builds deep conceptual knowledge and confidence.

## Features

- **High-Quality Mock Exams:** Practice with comprehensive mock exams for key CMFAS papers, including RES5, M9, M9A, and HI.
- **AI-Powered "Deeper Dives":** For every question, our AI generates a detailed mini-lesson that explains the core concept, provides real-world analogies, and clarifies why the correct answer is right. This turns every mistake into a valuable learning opportunity.
- **AI-Generated Hints:** Stuck on a question? Get a smart hint from the AI that guides you toward the correct answer without giving it away, sharpening your critical thinking skills.
- **Adaptive Practice Sessions:** The platform allows users to bookmark challenging questions. The AI can then generate a brand-new, unique practice quiz based on those bookmarks, creating targeted sessions to strengthen weak areas.
- **Mobile-First Design:** Our platform is fully responsive, turning any downtime—like a commute—into a productive study session on any device.
- **Multilingual Support:** Instant on-the-fly translations of questions and explanations to help learners for whom English is a second language.
- **Privacy by Design:** User privacy is paramount. We use secure authentication and all payments are handled by Stripe. We never store sensitive payment details.

## How It Works

1.  **Select an Exam:** The user chooses a mock exam to begin.
2.  **Practice & Learn:** As the user answers questions, they can request AI hints or, after answering, get a "Deeper Dive" explanation.
3.  **Bookmark Challenges:** Users can bookmark any question they find difficult.
4.  **Generate Smart Quizzes:** From their dashboard, users can launch an "AI Practice Session." Our Genkit-powered backend takes their bookmarked questions and generates a completely new quiz that tests the same concepts in different ways.
5.  **Master the Material:** By moving beyond simple memorization to true application, users build the confidence and competence needed to pass their exams.

This platform transforms exam preparation from a passive review process into an active, intelligent, and personalized learning journey.
