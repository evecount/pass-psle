# pass-psle.sg 🇸🇬

> **Clear the PSLE haze. Without the mental breakdown.**  
> An open, 100% free Singapore PSLE revision platform and student decompression anchor.

---

### Why this exists

PSLE is a pressure cooker for 12-year-olds in Singapore. Most tuition sites either paywall past-year questions or generate unpredictable AI explanations with high token bleed.

**pass-psle.sg** is built with zero AI runtime dependency:
1. **Zero Token Bleed**: Every single option has deterministic, pre-baked explanations detailing **why the correct answer is right** and **why common distractor options are wrong**.
2. **The "Talk Me Down" Anchor**: Immediate emotional decompression protocols (the 2-minute skip rule, in-hall panic unfreezing) and a direct tutor SOS channel.
3. **High-Yield Heuristics**: Direct model-drawing cheat sheets (Constant Difference, Remainder Branching, and Science Claim-Evidence-Reasoning chains).

---

### Stack
- **Framework**: Next.js (App Router) + TypeScript
- **Styling**: Tailwind CSS + Radix UI primitives
- **Cost**: $0/mo (Fully static/client deterministic execution, zero DB, zero AI API costs)
